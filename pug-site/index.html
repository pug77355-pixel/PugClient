Antivirus false positives

PUG Client hooks keybinds, reads game memory, and modifies network packets to add features — the same low-level behavior antivirus heuristics use to flag real malware. Tools like Windows Defender or SmartScreen may warn you even though the file isn't malicious. You can verify it yourself on VirusTotal, or submit a false-positive report to your AV vendor.

Server rules & anti-cheat

Many multiplayer servers explicitly ban utility/cheat clients like this one. Using it on a server that prohibits client modifications breaks that server's rules and can get your account banned there. This site does not help bypass anti-cheat detection — use is entirely at your own risk and subject to each server's own rules.
